# Security Policy

## Поддерживаемые версии

Поддерживается только актуальная ветка `4.3.x` (по мере выпуска). Более старые версии (`4.2.x` и ниже) исправления безопасности не получают.

## Сообщение об уязвимости

- Используйте **GitHub Security Advisories** (приватное сообщение владельцу репозитория).
- Публичные issue для просочившихся/подозреваемых уязвимостей не создавайте.
- Ожидаемое время первичного ответа — в течение 7 дней.

## Примечания

- Приложение хранит настройки в `%LocalAppData%\SmartUsbBackup\settings.json` и не отправляет пользовательские файлы наружу.
- Автообновление загружает установщик по HTTPS только с `github.com` и GitHub CDN; проверяется SHA-256 скачанного файла.
